# Java Backend Developer - Mis prácticas

Este repositorio contiene las prácticas que voy realizando con lo visto en
el curso de Java de Dev Senior Code.

Crecí en el campo y conozco de cerca sus problemas y su potencial. Estudio Ingeniería de Software y estoy aprendiendo Java 
para construir soluciones pensadas para el sector rural. Este repositorio es el registro de ese camino, desde el primer ejercicio.

## Módulo 1 - Clase 1
Mi primer programa en Java. Practiqué la estructura básica del lenguaje:
la clase, el método main, la impresión en consola, las variables y la
concatenación de texto.

## Módulo 1 - Clase 2
Aquí practiqué los tipos de datos (String, int, double), la declaración de
variables y los operadores aritméticos: suma, resta, multiplicación,
división y módulo.
